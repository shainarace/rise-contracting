RISE CONTRACTING WEBSITE

Open index.html in any web browser to view the website.

FILES
index.html       Home page
portfolio.html   Portfolio page
contact.html     Estimate request page
styles.css       All colors, fonts, spacing, and layout
script.js        Creates the contact-form email
images/          Logo and other site images
pictures/        Put completed-project photographs here

EDITING
All files can be opened in an ordinary text editor.

To add a portfolio photograph:
1. Put the photo in the pictures folder.
2. Open portfolio.html.
3. Replace a placeholder such as:
   <div class="project-image gold"><span>PROJECT PHOTO 01</span></div>

   with:
   <img class="project-image" src="pictures/kitchen-cabinets.jpg"
        alt="Newly installed kitchen cabinets">

Google Calendar scheduling can later be added by linking a button to a
Google Calendar Appointment Schedule. It does not require a backend.
